# BITZER Welcome Banner — Final

**Design:** Steel-frame three-panel nameplate (logo panel / deep-green WELCOME panel / message panel with engineering line art)
**Use for display:** `BITZER-Welcome-8K.jpg` (4320×7680) or `BITZER-Welcome-4K.png` (2160×3840)
**Full resolution (16K, 8640×15360):** `BITZER-Welcome-16K.png` / `.jpg`
**Editable source:** `bitzer-welcome.html` (fonts + logo embedded, edit text and re-render in a browser)
**Logo asset used:** `bitzer-logo.png` (background removed from uploaded official artwork)

To update the date/text: open `bitzer-welcome.html`, edit the `<text>` elements, then re-render to PNG/JPG at the desired resolution (e.g. headless Chromium screenshot at 4x device scale for 16K).
